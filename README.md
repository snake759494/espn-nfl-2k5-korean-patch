릴리즈에는 원본 디스크 이미지가 있어야만 쓸 수 있는 차분 파일(xdelta)만 첨부합니다.

## 적용 방법
1. 원본 `ESPN NFL 2K5 (USA).iso` 를 준비합니다(아래 해시 확인).

## 16:9 와이드 패치 (PCSX2)
한글패치는 실행 파일을 고치므로 PCSX2 가 게임을 구분하는 CRC 가 원본(42F9D5AF)과 달라집니다(**649B4F71**). 그래서 PCSX2 에 내장된 원본용 와이드 패치는 한글판에 자동 적용되지 않습니다.
원본용 패치(PCSX2 패치 DB, 제작 Arapapa)를 한글판 CRC 로 옮긴 `widescreen/SLUS-20919_649B4F71.pnach` 를 함께 배포합니다(릴리즈에도 첨부).

1. PCSX2 메뉴 **도구 → 데이터 디렉터리 열기** 로 데이터 폴더를 엽니다(보통 `문서\PCSX2`, 휴대용 설치면 PCSX2 폴더).
2. 그 안의 `patches` 폴더에 `SLUS-20919_649B4F71.pnach` 를 넣습니다(폴더가 없으면 만듭니다). 파일 이름은 바꾸지 마세요.
3. PCSX2 게임 목록에서 한글판 ISO 를 **오른쪽 클릭 → 속성 → 패치** 탭을 엽니다. 목록에 **"Widescreen 16:9"** 가 보이면 체크합니다.
   (게임 목록에 ISO 가 없다면 한 번 실행해 둔 뒤 다시 열거나, 실행 중 **시스템 → 게임 속성** 으로 열어도 됩니다.)
4. 게임을 실행하면 화면비가 16:9 로 바뀝니다. 끄려면 체크를 해제하세요.

- PCSX2 설정의 "와이드스크린 패치 사용" 옵션은 내장 패치용이라 이 파일과 관계없습니다.
- 메뉴·경기 화면은 16:9 로 넓어지고, 일부 그림 배경·동영상은 원래 4:3 비율입니다.
- 빌드가 바뀌면 CRC 도 바뀌므로 `python tools/wscrc.py` 로 새 CRC 를 확인하세요(새 릴리즈에는 항상 맞는 파일을 함께 첨부합니다).

## 기술 요약
- 게임 문자열은 UTF-16 이며 원래 글꼴 9종은 ASCII 뿐입니다. 한글 음절을 사용자 영역 코드 0xE000+순번으로 넣고,
  공용 한글 글꼴 리소스 `fontk`(512×512 4bpp, 128KB) 하나를 추가했습니다(경기 중 여유 메모리가 약 0.8MB라 글꼴마다 넣을 수 없음).
- 실행 파일의 글자 폭·글자 그리기 루틴을 고쳐, 한글은 fontk 의 칸을 **그리는 글꼴의 대문자 높이·베이스라인에 맞춰 확대/축소**해 그립니다.
- 작전명은 플레이북·실행 파일·튜토리얼·플레이 화면에 같은 번역을 넣어 게임 내부의 이름 검색이 어긋나지 않게 했습니다.
- 자세한 내용: `docs/TECHNICAL.md`, 빌드: `docs/BUILD.md`, 변경 기록: `CHANGELOG.md`, 권리: `RIGHTS.md`
