# 빌드 검증 (v1.3)
- `prepare.py` 로 원본 ISO 에서 다시 만든 원문 묶음 18,011개가 번역 당시 묶음과 바이트 단위로 동일.
- 빌드 시 칸 길이 초과 0건.
- xdelta 를 원본에 적용한 결과 ISO 가 빌드 결과와 해시 일치(SHA-256 `f0c693a7…3a7c99`).
- PCSX2: 메인 메뉴·VIP 생성·응원 팀·빠른 경기 팀 선택·코치 대결·경기 진입(동전 던지기, 선수 카드) 진행과 한글 표시 확인, 선수·코치 얼굴·필드 텍스처 정상.
- 사용자 스크린샷 109장 검토 후 지적된 화면(플레이북 책, 버튼 안내문, 메모리 카드 팝업, 크립) 보완.
- 전수조사(`tools/audit.py`): 남은 영문은 저작권 표기·웹 주소·제품 약어·데이터 조각·내부 키·의도적 원문 유지 항목.
- 16:9 와이드 패치: 한글판 실행 파일 CRC 649B4F71, 와이드 패치 대상 3곳 명령이 원본과 동일, PCSX2 v2.9 에서 "게임 패치 활성화·화면비 16:9" 로그와 메뉴·팀 선택·경기 화면 16:9 출력 확인.
- v1.1: 경기 중 작은 점수판 쿼터 칸 "1st" 표시를 원본과 같게 확인(킥오프 후 연속 캡처, `tools/sbtest.py`). 원인 문자열은 실행 파일 번역을 오프셋 범위로 이분 탐색해 특정(`KO_ELFRANGE`).
- v1.2: 더빙 클립 19,768개 반영(원본 대비 클립 데이터 변경 확인), 실행 파일 CRC 649B4F71 불변, PCSX2 에서 경기 진입까지 정상 진행. 숫자는 합성기가 잘 못 읽어 한자어 수사로 바꿔 합성(`dub.ko_num`), 표본 클립을 한국어 음성 인식으로 대본과 대조.
- v1.3: 해설 29,737·아나운서 228·외침 278 클립과 동영상 16편 더빙 반영, 실행 파일 CRC 649B4F71 불변, xdelta 적용 결과 해시 일치, PCSX2 에서 부팅 인트로 영상·메뉴·경기 진입 정상. 동영상 더빙은 한국어 음성 인식으로 대본과 대조.
