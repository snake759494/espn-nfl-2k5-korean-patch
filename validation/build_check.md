# 빌드 검증 (v1.0)
- `prepare.py` 로 원본 ISO 에서 다시 만든 원문 묶음 18,011개가 번역 당시 묶음과 바이트 단위로 동일.
- 빌드 시 칸 길이 초과 0건.
- xdelta 를 원본에 적용한 결과 ISO 가 빌드 결과와 해시 일치(SHA-256 `6296d59a…6446ca`).
- PCSX2: 메인 메뉴·VIP 생성·응원 팀·빠른 경기 팀 선택·코치 대결·경기 진입(동전 던지기, 선수 카드) 진행과 한글 표시 확인, 선수·코치 얼굴·필드 텍스처 정상.
- 사용자 스크린샷 109장 검토 후 지적된 화면(플레이북 책, 버튼 안내문, 메모리 카드 팝업, 크립) 보완.
- 전수조사(`tools/audit.py`): 남은 영문은 저작권 표기·웹 주소·제품 약어·데이터 조각·내부 키·의도적 원문 유지 항목.
