# ESPN NFL 2K5 해설 한국어 더빙 대본 지침

## 입력·출력
- 입력 `work/dub_batches/dub_NNNNN.json`: `[{id, en, dur, max, prev, next}]`
  - `en`: 원본 해설 클립을 자동 받아쓰기한 영어(오인식이 많음), `dur`: 클립 길이(초), `max`: 한국어 **음절 수 한도**
  - `prev`/`next`: 바로 앞·뒤 클립의 받아쓰기(문맥용)
- 출력 `translation/dub/dub_NNNNN.json`: `{"<id>": "<한국어 대본>"}`. 대본을 확신할 수 없으면 `""`(빈 문자열 = 원본 영어 음성 유지).

## 게임 구조 (중요)
- 경기 중계(캐스터)와 해설위원 대사가 **조각 단위**로 녹음돼 있고, 게임이 조각을 이어 붙여 말합니다.
  예: "Carries this off his left tackle, and..." 다음에 "for a gain of five" 같은 조각이나 **선수 이름 음성(영어 그대로 남음)**이 붙습니다.
- 같은 문장이 끝맺음만 다른 두 가지로 녹음된 경우가 많습니다(이어지는 형 "…, and" / 끝나는 형 "…."). 번호가 인접한 비슷한 클립은 짝입니다.
  - 이어지는 형 → 한국어도 이어지는 어미: "~하고,", "~하면서," / 끝나는 형 → "~합니다.", "~네요!"
- 문장 앞부분 조각(예: "Ladies and gentlemen,")이나 숫자·거리 조각(예: "for a gain of 12", "from the 30")은 앞뒤에 다른 조각이 붙어도 어색하지 않게 짧고 독립적으로.
- 선수 이름·팀 이름이 클립 안에 직접 들어 있으면 한국어 음역(예: Favre → 파브, 49ers → 포티나이너스, Rams → 램스).

## 받아쓰기 오류 바로잡기
- 받아쓰기는 소리만 듣고 적은 것이라 틀린 단어가 많습니다. **풋볼 중계 문맥으로 원래 말을 추정**해 번역하세요.
  예: "left taco" → left tackle, "Bulldoses right in center" → bulldozes right up the middle, "Like, subscribe" → (짝 클립 문맥상) "~off right guard, and" 류.
- 짝·앞뒤 클립을 보고도 추정이 불가능하면 `""`.
- 의미 없는 소리(함성·웃음·숨소리)만 있는 클립은 `""`.

## 문체
- 캐스터: 생동감 있는 TV 중계체("~합니다!", "~입니다!", 진행형 "~하고 있습니다"). 해설위원: 분석하는 말투("~이네요", "~거든요", "~죠").
- 짧고 리듬감 있게. 영어 직역보다 한국 중계에서 실제로 쓰는 표현(예: touchdown → 터치다운!, first down → 퍼스트 다운, sack → 색, interception → 인터셉트, fumble → 펌블).
- 용어는 `translation/STYLE.md` 용어집을 따릅니다.

## 길이 (하드 제한)
- 한국어 음절 수(한글 1음절 = 1, 숫자·영문 1자 = 1, 공백·문장부호 제외) ≤ `max`. 클립 길이 안에서 말해야 하므로 짧게.
- 숫자는 한글로 읽힐 형태로 써도 됩니다(예: "12야드" 그대로 OK).
- 허용 문자: 한글 완성형, 숫자, 공백, `. , ! ? ' -`. 영문 알파벳은 쓰지 마세요(합성기가 영어로 읽음).
